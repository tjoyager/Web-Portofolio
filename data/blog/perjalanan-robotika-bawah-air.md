# Memulai Perjalanan di Dunia Robotika Bawah Air

Robotika bawah air adalah bidang yang sangat menarik dan menantang. Ketika saya pertama kali bergabung dengan **Tim Riset Banyubramanta ITS**, saya tidak menyangka betapa kompleksnya dunia ini.

## Kenapa Robotika Bawah Air?

Laut menutupi lebih dari 70% permukaan bumi, namun kita baru menjelajahi kurang dari 5% dari dasar laut. Autonomous Underwater Vehicles (AUV) adalah kunci untuk membuka misteri ini.

## Tech Stack yang Saya Pelajari

Beberapa teknologi yang saya pelajari selama di Banyubramanta:

- **ROS 2 (Robot Operating System)** — Framework utama untuk komunikasi antar node
- **Gazebo** — Simulator untuk testing sebelum deploy ke hardware
- **OpenCV + YOLO** — Computer vision untuk deteksi objek bawah air
- **ArduSub** — Firmware untuk kontrol thruster

## Tantangan Terbesar

Tantangan terbesar dalam robotika bawah air adalah komunikasi. Sinyal radio tidak bekerja di bawah air, jadi kita harus menggunakan sistem akustik atau tethered connection.

## Apa Selanjutnya?

Saya berencana untuk mendalami **6-DoF control systems** dan berkontribusi lebih banyak pada software stack tim kami. Stay tuned untuk update selanjutnya!

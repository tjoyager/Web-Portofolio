# Panduan Setup ROS 2 di Ubuntu untuk Pemula

Jika kamu baru memulai belajar robotika, ROS 2 adalah framework yang wajib kamu kuasai. Berikut panduan setup-nya.

## Persyaratan

- Ubuntu 22.04 LTS
- Minimal 4GB RAM
- 20GB free disk space

## Langkah 1: Setup Locale

Pastikan locale kamu sudah benar. Ini penting agar ROS 2 berjalan dengan baik.

## Langkah 2: Add Repository

Tambahkan repository ROS 2 ke sistem kamu.

## Langkah 3: Install ROS 2

Install ROS 2 Humble desktop version yang sudah termasuk rviz dan demo nodes.

## Langkah 4: Test Instalasi

Jalankan demo talker-listener untuk memastikan instalasi berhasil.

## Tips Tambahan

- Selalu source setup.bash di setiap terminal baru
- Gunakan colcon sebagai build tool
- Pelajari konsep node, topic, service, dan action

Selamat belajar ROS 2! 🤖
